# MAX-бот ГрантХаб

Инструкция настройки — в [корневом README](../README.md).

- `src/bot.js` — создание бота и обработчики команд; конфигурация передаётся аргументами. Импорт не запускает polling и не загружает секреты.
- `src/index.js` — точка запуска: читает корневой `.env`, проверяет API и запускает polling.
- `test/bot.test.js` — тесты с имитацией API, без сообщений реальным пользователям.

Запуск из корня: `npm run bot` (API уже должен работать). Проверка: `npm --prefix my-bot run check`, тесты: `npm --prefix my-bot test`.

Бот не имеет своей БД или JSON-каталога. Регистрация пользователей проходит через защищённый внутренний маршрут бэкенда. Анкеты и избранное редактируются в мини-приложении; напоминания отправляет бэкенд.
