# Web-интерфейс ГрантХаб

Общие команды запуска и описание архитектуры — в [корневом README](../README.md).

- `src/app` — точка сборки интерфейса и подключённые стили.
- `src/pages` — экраны и загрузка данных приложения.
- `src/widgets` — навигация; `src/features` — фильтры и действия с избранным.
- `src/entities` — гранты и профиль бизнеса; `src/shared` — общие UI, HTTP-клиент, MAX Bridge и ресурсы.

Данные приходят только из API. Токен сессии хранится в памяти вкладки; серверные секреты не должны попадать в `VITE_*`. В разработке `/api` проксируется на бэкенд; после сборки `dist` отдаёт тот же API-сервер.

Из корня проекта: `npm run dev`, `npm run build`, `npm run check`, `npm test`. Только фронтенд: `npm --prefix grants run lint` и `npm --prefix grants test`.
